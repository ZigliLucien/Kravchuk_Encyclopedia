All indices run from $0$ to $N$. Column vectors and the standard basis are used:
\[
R e_j=(N-j)e_{j+1},\qquad L e_j=j e_{j-1},\qquad A=R+L.
\]
The polynomial and symmetric matrix conventions are
\[
(1+v)^{N-j}(1-v)^j=\sum_{n=0}^N\Phi_{nj}v^n,
\qquad B=\operatorname{diag}\binom Nj,\qquad S=\Phi B.
\]
The matrix $A$ is not symmetric in this basis. Exact checks give
\[
A\Phi=\Phi\Lambda,\quad\Phi A=\Lambda\Phi,\quad
\Phi^2=2^NI,\quad S^T=S,\quad [L,R]=\Lambda,
\qquad \Lambda_{jj}=N-2j.
\]
