# Kravchuk Encyclopedia — AMS book skeleton

Compile `main.tex` with `pdflatex main.tex` twice, or use `latexmk -pdf main.tex` when available. Upload this entire folder to Overleaf with main.tex as the main document.

The 18 main chapters follow Section 6.1 of KravFeinsKocik.tex. Six appendix chapters follow its appendix list. Extra archived headings are incorporated, including FFT, integral zeros, Heisenberg Clebsch–Gordan coefficients, supersymmetry, twistons, and introductory matrix topics. Editorial additions (binomial bases, Mehler kernels, and the beta-kernel spectral program) are deliberately separate sections.

Each chapter is an independent file. Most sections are empty with commented TODOs. Starter material supplies elementary definitions, orthogonality, recurrences, the urn chain, fixed-degree Hermite scaling, and the exact beta identity. The conjectural global spectral asymptotic is explicitly distinguished from proved identities.

No external literature search was performed: no unverified bibliographic metadata were added. A source register is included; the literature bibliography is intentionally left for verified additions. Historical biography and numerical tables remain empty.

website-heading-inventory.json preserves every archived HTML heading, including administrative pages not promoted to book content. source-outline.tex.txt preserves the extracted article outline. CONTENTS.md gives a plain-text chapter outline.

The original uploads are not changed or copied into this project. The archived Java/Perl/CGI programs are not executed or included. This delivery is LaTeX source, not a compiled PDF.
