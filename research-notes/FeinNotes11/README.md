# FeinNotes11 editable LaTeX

FeinNotes11.tex is a working editorial transcription based on the page readings retained in the conversation. The original scan was not available for a fresh visual check. It preserves the four original sections and the final open question; original typo readings are preserved in source comments, and corrections are listed in an appendix.

Fourier convention: {\cal F}^{*} has kernel exp(+i xi x)/sqrt(2 pi), and is the adjoint/inverse of the negative-exponent transform.

Compile FeinNotes11.tex with a standard LaTeX distribution. No PDF build is supplied. The Encyclopedia and spectral working note have not been changed by this conversion.
